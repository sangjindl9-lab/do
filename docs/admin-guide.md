# 관리자 사용설명서

접속: `https://<서비스 주소>/admin` → 아이디 `admin`, 비밀번호는 Railway 환경변수 `ADMIN_PASSWORD`.
로그인 5회 실패 시 15분간 잠깁니다.

## 처음 할 일

1. **시스템 설정 > 환경 설정**: 고객지원 이메일, SMTP(이메일 발송), 필요 시 AI·Google OAuth 등록
2. **고객지원 > 약관·정책**: 사업자 정보와 세부 조항 확정
3. **결제관리 > PG 설정**: 토스페이먼츠 키 등록 → [PG 등록설명서](pg-setup.md)
4. **장비관리 > PC 에이전트**: 에이전트 등록 → 등록 코드를 제어 PC에 입력 → [설치설명서](agent-install.md)
5. **장비관리 > 폰팜 통합 관리**: 기기가 올라오면 기기를 열어 "Google 계정 로그인 확인함" 체크, 이름·그룹 정리

## 원격 제어

승인된 명령만 보낼 수 있습니다: 화면 확인(스크린샷), 상태·저장공간 확인, 허가된 APK 설치, 앱 실행·종료·버전 조회·삭제(등록된 검사 대상 앱만), ADB 재연결, 재부팅.
임의 셸 명령은 지원하지 않습니다. 모든 명령은 관리자 활동 기록에 남습니다.
웹의 "화면 확인"은 스크린샷 방식이며, 연속 미러링은 제어 PC의 에이전트 창에서 scrcpy로 실행합니다.

## 모의(MOCK) 환경

PG 설정을 "모의 결제 환경"으로 두고 종류가 "모의 장비"인 에이전트를 등록하면 실물 장비·PG 없이 전체 흐름을 시험할 수 있습니다.
모의 주문에는 모의 기기만, 실제 주문에는 실기기만 배정되며 화면·보고서·매출에 MOCK으로 구분됩니다. **운영 개시 전 모드를 반드시 테스트/운영으로 바꾸세요.**
