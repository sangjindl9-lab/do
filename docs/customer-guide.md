# 고객 사용설명서

1. **회원가입**: 이메일·비밀번호(8자 이상, 영문+숫자)·이름 입력, 약관 동의. 인증 메일의 링크를 누르면 이메일 인증이 끝납니다.
> 2026-11-25 변경: 앱 등록은 **Play Store 링크 또는 패키지명 한 칸**만 입력하면 됩니다. 공개 스토어에 있는 앱은 이름·아이콘·설명을 자동으로 불러오고, 비공개 테스트 단계라 조회되지 않는 앱만 이름을 직접 입력합니다. 등록하면 "Play 스토어 배포본" 버전이 자동으로 만들어져 APK 없이 바로 신청할 수 있습니다. 이 방식은 앱 상세의 **검사 기기 계정 목록**(CSV)을 Play Console 비공개 테스트의 테스터 이메일 목록에 추가해야 기기에 설치됩니다. 앱 상세 화면에서 현재 상태, 예약 작업, 리포트, 일별 실행 기록(기기별 실행 화면)을 봅니다.

2. **앱 등록** (대시보드 > 앱 등록·관리): 앱 이름, 패키지명(`com.example.app` 형식), 필요 시 Play 주소·비공개 테스트 링크·테스트용 로그인 정보(암호화 저장). **검사 권한 보유 확인**에 동의해야 등록됩니다.
3. **버전 등록**: 앱 상세에서 버전·버전 코드를 입력하고 APK를 올립니다. 업로드 진행률이 표시되고 실패하면 "다시 시도"할 수 있습니다.
   - APK 형식·패키지명 일치·중복 여부를 검사하며, 이상 파일은 격리되어 검사에 쓸 수 없습니다.
   - APK가 없으면 설치 검사는 '미수행'으로 기록됩니다(기기에 앱이 이미 설치된 경우에만 실행 검사 가능).
4. **신규 테스트 신청**: 앱·버전 → 상품 → (선택) 시나리오·희망 시작일·희망 Android 버전·쿠폰 → 주문하고 결제하기.
5. **결제**: 카드·간편결제 또는 계좌이체. 결제가 확인되면 기기가 자동 배정됩니다. 가용 기기가 부족하면 '기기 배정 대기'가 되고 확보되는 즉시 시작하며, 검사 기간은 시작 시점부터 계산합니다.
6. **진행 현황** (주문·진행 현황 > 주문 선택): 진행률, 남은 기간, 배정·연결 기기 수, 성공률, 일별 결과, 성능 측정값.
   - 기기별 현황 / 검사 결과(단계별 기대·실제 결과) / 오류·크래시(로그, 규칙 기반 분류, AI 추정은 '미확인' 표시) / 스크린샷 / 보고서 탭
7. **보고서**: 기간 종료 시 완료보고서가 자동 발행됩니다. 진행 중에도 종합·일별·기기별·버전별·오류 분석·성능·스크린샷 보고서를 PDF(상품에 따라 Excel)로 생성·다운로드할 수 있습니다.
8. **검사 시나리오**: 앱 실행, 요소 검색, 버튼 선택, 텍스트 입력, 스크롤, 대기, 화면 캡처, 요소·텍스트 검증 등을 단계로 구성합니다. 요소는 resource_id / text / content_desc로 지정합니다. 입력 텍스트에 `{{login_id}}`, `{{login_password}}`를 쓰면 등록한 테스트 로그인 정보가 들어갑니다. 수정하면 새 버전으로 저장되고 이력이 남습니다.
9. **Google Play 비공개 테스트 관리** (앱 상세): 실제 테스터 이메일 관리·CSV 내보내기, 참여 확인·피드백 기록, 테스트 경과일, 프로덕션 신청 참고자료 초안. 실제 테스터 수 / 실기기 자동 검사 기기 수 / 기기 Google 계정 확인 수는 서로 다른 항목으로 표시됩니다.
10. **고객 문의 / 알림 / 결제 내역 / 마이페이지**(정보 변경, 비밀번호 변경, 로그인 기록, 회원 탈퇴).

환불은 고객 문의로 요청하면 환불 정책에 따라 처리됩니다.

## Play 스토어 배포본 검사 흐름 (v1.0.1)

1. Play Console에서 비공개 테스트 트랙에 앱을 출시한다.
2. 대시보드 **테스터 목록** 메뉴에서 CSV를 받아 Play Console > 비공개 테스트 > 테스터 > 이메일 목록에 모두 추가한다.
3. **앱 등록**에서 확인 항목 5개를 모두 체크하면 입력란이 열린다. Play Store 링크 또는 패키지명만 넣으면 앱 정보를 불러온다.
4. 테스트를 신청·결제하면 기기가 배정된다. 앱 화면의 **설치 요청**을 누르면 검사 기기가 테스트 참여 → Play 스토어 설치 → 실행을 차례로 수행한다.
5. 12대(상품 기기 수가 더 적으면 그 수) 이상 설치되면 그 시점부터 테스트 기간이 시작된다.
6. 이후 매일 오전 2시(한국시간)에 앱을 실행하고 2초 뒤 화면을 캡처한다. 스토어에 새 버전이 있으면 실행 전에 업데이트하며, 업데이트 후 첫 실행은 일별 실행 기록에 청록 테두리로 표시된다.

테스터 목록의 계정은 본 서비스가 운영하는 검사 기기의 계정이며 사람 테스터가 아니다. 프로덕션 신청 가능 여부와 승인은 Google Play가 판단하며 본 서비스는 이를 보장하지 않는다.
실제 기기에서의 테스트 참여·스토어 설치·업데이트 동작(ADB)은 모의 기기로만 검증되었고 실기기 검증은 대기 상태다.

## 가격 및 환불 정책 (2026-11-25)

- 단일 요금제: 앱 1개당 8,000원(부가세 포함), 검사 기기 16대, 18일(필수 14일 + 여유 4일). 기존 BASIC~ENTERPRISE 상품은 판매 중지 상태이며 관리자 > 상품에서 다시 켤 수 있다.
- 무료 연장: 테스트 시작 후 14일 안에 업데이트 2회 이상이 확인되면 앱 화면의 **무료 연장**으로 18일을 1회 연장한다. 종료된 테스트의 연장은 고객 문의로 처리한다.
- 환불: 12대 이상 설치되어 테스트가 시작되기 전에는 앱 화면의 **환불 신청**으로 즉시 전액 환불(결제 취소)된다. 시작 후와 TWA 앱은 환불 불가. 서비스 장애 환불은 고객 문의 → 관리자 > 결제에서 처리한다.
- TWA 여부는 자동 판별하지 않으며 관리자가 확인한다.
