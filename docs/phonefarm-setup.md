# 폰팜 장비 연결설명서

대상: Phone Farm Box 20-in-1(갤럭시 S20 메인보드 20개 구성 등), USB 또는 LAN, 표준 ADB.

## 1. 네트워크

- 장비와 제어 PC는 **검사 전용 네트워크**(사내 업무망과 분리된 VLAN/공유기)에 두는 것을 권장합니다.
- 제어 PC는 서버로 나가는 HTTPS(443)만 필요합니다. ADB 포트(5555 등)를 인터넷에 열지 마세요.

## 2. 각 기기 준비 (운영자가 직접)

1. 개발자 옵션 > **USB 디버깅** 켜기 (LAN 방식 장비는 제조사 안내에 따라 무선/네트워크 ADB 활성화)
2. 제어 PC 연결 시 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 **항상 허용**
3. 화면 잠금 해제(없음), 화면 자동 꺼짐 최대, 자동 업데이트·절전 최소화
4. **Google 계정을 기기에서 직접 로그인**합니다. 프로그램은 Google 계정 비밀번호를 수집·저장하지 않습니다.
5. 관리자 페이지에서 기기를 열어 "Google 계정 로그인 확인함"을 체크합니다(운영자 확인 항목).

## 3. 연결 확인

```bash
adb devices            # 20대가 모두 'device' 상태인지 확인 ('unauthorized'면 기기에서 디버깅 허용)
adb connect 192.168.50.101:5555     # LAN 방식 장비
gat-agent devices      # 에이전트가 인식한 기기 목록
```

에이전트가 실행 중이면 기기가 자동 등록되어 관리자 페이지 > 폰팜 통합 관리에 나타납니다.
수집 정보: Serial, 제조사, 모델, Android·SDK 버전, CPU, RAM, 저장공간, 배터리, 온도, 해상도, 네트워크, 연결 상태, 설치된 검사 대상 앱과 버전.

## 4. 상태

대기 중 / 배정 완료 / 검사 중 / 오프라인 / 오류(디버깅 미허용) / 과열(기본 45℃ 이상) / 저장공간 부족(기본 1GB 미만) / 유지보수 / 사용 중지.
과열·저장공간 부족 기기에는 작업을 보내지 않으며, 30분 이상 오프라인이면 배정을 다른 기기로 교체합니다(기준은 환경 설정에서 변경).

## 5. 확장

장비 박스·제어 PC를 추가할 때마다 에이전트를 하나씩 등록합니다. 에이전트당 동시 검사 수는 관리 창의 "동시 검사 기기 수"와 서버 설정 `limits.max_jobs_per_agent`(기본 20)로 조절합니다.
통신 방식이 다른 장비는 `android-engine/gat_engine/provider.py`의 `DeviceProvider`를 구현해 추가합니다.

## 참고: 검사 중 기기에서 일어나는 일

APK 설치(`adb install -r -g`) → 실행(`am start -W`) → 화면 덤프(UIAutomator) → 방향 전환 → 홈/복귀 → 성능(`dumpsys meminfo/cpuinfo/diskstats/battery`) → 시나리오 → (USB 연결 기기만) 네트워크 차단 검사 → 종료·재실행 → Logcat 수집.
LAN(TCP) 연결 기기는 ADB 연결 유지를 위해 네트워크 차단 검사를 '미수행'으로 기록합니다.
검사 기간이 끝나면 고객 앱 삭제 명령을 보냅니다(환경 설정 `retention.cleanup_app_after_test`).
