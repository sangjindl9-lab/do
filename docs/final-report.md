## 2. 구현 완료 및 외부 연동 대기

코드는 있으나 인증정보가 없어 실제 왕복을 실행하지 못한 항목입니다.

| 항목 | 필요한 것 |
| --- | --- |
| 이메일 실제 발송(대기열·템플릿·재시도는 검증됨) | SMTP 정보 → 관리자 > 환경 설정 |
| Google OAuth 로그인 | OAuth Client ID/Secret → 환경 설정 |
| AI 오류 분석(OpenAI·Claude·Gemini·로컬·사용자 지정) | API 키 → 환경 설정 |

## 3. 실제 장비 검증 대기

- 표준 ADB 제어 전체(`AdbProvider`). 명령은 Android 표준 도구 기준으로 작성했으나 **실기기에서 한 번도 실행하지 못했습니다.** 기종·Android 버전에 따라 출력 형식이 달라 파싱 보정이 필요할 수 있습니다(특히 전면 앱 판별, `diskstats` 저장공간, 런처 액티비티 조회).
- 20대 동시 검사 부하, 과열·저장공간 임계값, LAN 방식 장비 연결
- Windows 설치 마법사 수동 실행·트레이 동작, Windows 서비스 상시 운용, Linux systemd 설치
- scrcpy 미러링, Appium 드라이버(선택 기능)

## 4. 실제 PG 인증정보 대기

- 토스 결제창 호출(브라우저 SDK), 승인·취소 API 실제 왕복, 웹훅 실제 수신
- 테스트 키로 먼저 확인한 뒤 운영 키로 전환하세요([pg-setup.md](pg-setup.md)).

## 5. 미구현 또는 요구와 다르게 구현한 것

| 요구 | 실제 |
| --- | --- |
| Next.js | Vite(React SPA). 서비스 1개로 운영하기 위해 변경 |
| 웹에서 기기 화면 실시간 확인 | 스크린샷 요청 방식. 연속 미러링은 제어 PC의 에이전트 창에서 scrcpy |
| 에이전트 자동 업데이트 | 새 버전 알림 + 다운로드 페이지 열기(무인 자동 교체 없음) |
| MSI 설치 파일 | EXE(Inno Setup)만 제공 |
| 악성 APK 격리 | 구조 검증·패키지명 불일치·경로 조작 탐지 후 격리. **백신 엔진 검사는 없음** |
| 다국어 | 공개 페이지·고객 화면 한국어/영어. 관리자 화면은 한국어만. 일본어·중국어는 사전 추가 구조만 |

| CSRF 방어 | 쿠키 인증을 쓰지 않고 Authorization 헤더 토큰만 사용해 CSRF가 성립하지 않는 구조(별도 토큰 없음) |

| 파일 전송·시나리오 원격 실행 | 서버 API와 에이전트는 구현, **관리자 화면에 버튼 없음** |
| 실제 참여 확인 자료 관리 | 상태·피드백 기록만 가능(증빙 파일 첨부 없음) |
| 데이터 보존기간 | 알림·하트비트만 자동 정리. 검사 결과·스크린샷의 기간 경과 자동 삭제는 없음 |
| 개인정보 삭제 | 탈퇴 시 계정 익명화. 앱·주문·검사 기록은 남음 |
| 실시간 갱신 | 화면은 주기 조회(5~30초) 방식 |

## 6. 운영 전 확인할 점

0. **GitHub 푸시 자동 배포**: 저장소 연결 직후의 푸시 2건이 자동으로 배포되지 않아 저장소를 다시 연결해 최신 커밋을 배포했습니다. 이후 푸시가 자동 배포되는지는 Railway 서비스 > Deployments에서 확인해 주세요. 안 되면 Railway > 서비스 > Settings > Source에서 저장소를 다시 연결합니다.

1. **서비스명**: "Google"은 Google LLC의 상표입니다. 화면·약관·보고서에 비공식 서비스임을 표시했지만, 서비스명 자체에 대한 상표 문제는 표시만으로 해소되지 않을 수 있으니 출시 전 검토를 권합니다.
2. **Google Play 정책**: 이 시스템은 자동 검사 기록을 인간 테스터 참여로 표시하지 않습니다. 폰팜 기기에 로그인한 계정을 비공개 테스트 참여 인원으로 쓰는 것은 Google Play 정책 위반 소지가 있으며, 이 시스템이 그 용도를 지원하거나 보장하지 않습니다.
3. 약관·개인정보처리방침·환불 정책은 초안입니다. 사업자 정보와 조항을 확정해 주세요.
4. `SECRET_KEY`를 바꾸면 저장된 PG·SMTP 키를 다시 입력해야 합니다.
5. 운영 개시 전 PG 모드가 "모의 결제 환경"이 아닌지 확인하세요(현재 "결제 비활성화").

5. 테스트 키 결제·환불 → 운영 키 전환
